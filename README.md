# PythonProject_kurs_work
## Описание проекта
Проект реализует различные функции работы с банковскими операциями клиента
## Структура проекта
* src/ -папка, где находятся основные модули работы с банковскими операциями клиента
* src/views.py - модуль главной страницы, который собирает данные по транзакциям, картам, валютам и акциям.
* src/utils.py - модуль для обработки финансовых данных и интеграции с внешними API
* src/reports.py - Модуль для генерации и сохранения финансовых отчетов в формате JSON.
* src/services.py - модуль для аналитики и поиска по финансовым транзакциям.
* src/main.py - главный модуль
* src/config - конфигурационный модуль для управления путями и настройками приложения.

* tests/ - папка с тестами проекта
* data/ - папка, где хранится файл с данными о финансовых транзациях operations.xlsx
* logs/ - папка, хранящая записи логов
* mian - запускающий модуль
* poetry.lock - зависимости проекта
## Установка
Склонируйте репозиторий:


`git clone git@github.com:Ekaterina649/project_Skypro_kurs_work.git`

## Установка и запуск
Для того, чтобы запустить проект сначала нужно установить зависимости.

`poetry install`

Создайте файл .env на основе .env_template
Заполните необходимые API-ключи:

EXCHANGE_API_KEY - ключ для Exchange Rates API

STOCK_API_KEY - ключ для Alpha Vantage API

В проекте есть запускающий модуль main.py, который является точкой входа в программу.
Запустите его.

`poetry run python src/main.py`

## Пример использования

После запуска вам будет доступно меню с опциями:

Сводная информация - обзор финансовой ситуации

Анализ кешбэка - оценка эффективности бонусных программ

Поиск транзакций - поиск конкретных операций

Отчет по категории - детальный анализ расходов

Выход - завершение работы

## Тестирование
Запуск всех тестов:

`pytest tests/`

Запуск тестов с измерением покрытия:

`pytest --cov`

## Формат данных 
Приложение ожидает Excel-файл со следующими колонками:

Дата операции - в формате DD.MM.YYYY HH:MM:SS

Сумма платежа - числовое значение

Категория - категория операции

Описание - описание транзакции

Статус - статус операции (OK/FAIL)

Номер карты - последние 4 цифры карты

Бонусы (включая кэшбэк) - сумма кешбэка

## Логирование
Приложение ведет детальное логирование в папке logs/:

utils.log - логи обработки данных

views.log - логи главной страницы

services.log - логи сервисов аналитики

reports.log - логи генерации отчетов
